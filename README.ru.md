# OnlineSubsTranslator

[English](README.md) · **Русский** · [Релизы](https://github.com/FreTEZ-02/OnlineSubsTranslator-Releases/releases)

OnlineSubsTranslator — настольное приложение для ручного перевода субтитров. Редактор открывается в браузере. Можно импортировать субтитры с YouTube или из файла SRT, редактировать текст и тайминги и скачать готовый перевод в SRT. Whisper также может распознавать речь на устройстве.

## Как получить приложение

Зашифрованные пакеты обновлений доступны на [странице релизов](https://github.com/FreTEZ-02/OnlineSubsTranslator-Releases/releases). Для закрытого тестирования получите у владельца проекта установщик для вашей системы и подписанный файл доступа `.ostkey`. Установщик сам подберёт сборку для вашего компьютера.

## Установка и запуск

- **Windows.** Распакуйте ZIP целиком через **«Извлечь всё»**. В получившейся папке откройте `Install-OnlineSubsTranslator.cmd`.
- **macOS 13 Ventura или новее.** Распакуйте ZIP в Finder и откройте `OnlineSubsTranslator.app`. При первом запуске доверенной копии macOS может запросить подтверждение. [Инструкция Apple для первого запуска](https://support.apple.com/ru-ru/102445)
- **Linux.** Распакуйте архив и запустите `Install-OnlineSubsTranslator.sh` из получившейся папки. Если файловый менеджер открывает его как текст, откройте терминал в этой папке и выполните `sh ./Install-OnlineSubsTranslator.sh`.

При первом запуске выберите файл `.ostkey` в браузере и нажмите **«Установить»**. Для дальнейшей работы открывайте тот же установщик. Скачанное обновление применится при следующем запуске.

После установки редактор откроется в браузере по умолчанию. Если вкладка не открылась автоматически, перейдите по адресу `http://127.0.0.1:4174/`. Язык редактора можно выбрать в верхней панели, **Русский** или **English**.

## Перевод и экспорт

1. Вставьте ссылку на ролик и импортируйте дорожку субтитров или откройте SRT с компьютера.
2. Выберите реплику, введите перевод и при необходимости измените тайминги.
3. Нажмите **«Скачать SRT»**, чтобы сохранить заполненные реплики.

Перед первым запуском Whisper откройте **«Самопроверка» → «Проверить и восстановить»**. Для загрузки моделей нужен интернет.
